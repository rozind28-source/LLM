# 🚀 Как запустить систему

## Быстрый старт (одна команда)

```bash
npm run launch
```

Эта команда автоматически:
1. ✅ Проверит наличие `keys.json`
2. ✅ Запустит синхронизатор (загрузит каталог провайдеров)
3. ✅ Поднимет runtime-сервер на порту 3001
4. ✅ Запустит дашборд на порту 3000
5. ✅ Откроет браузер

---

## Если нужно запустить по шагам

### 1. Установите зависимости

```bash
npm install
```

### 2. Добавьте API-ключи через дашборд

После запуска откроется дашборд на вкладке **«⚙️ Настройка»**:

1. Нажмите **«Получить ключ»** рядом с нужным провайдером (рекомендуем **Groq**)
2. Скопируйте ключ с сайта провайдера
3. Вставьте ключ в поле в дашборде
4. Нажмите **«Сгенерировать keys.json»**
5. Нажмите **«Скачать»** — файл сохранится автоматически

> 💡 Или вручную: `cp keys.json.example keys.json` и отредактируйте файл

### 3. Запустите синхронизатор

```bash
npm run sync
```

### 4. Запустите сервер

```bash
npm start
```

### 5. Откройте дашборд (в другом терминале)

```bash
npm run dev
```

Откройте http://localhost:3000

---

## Тестовый запрос

```bash
curl -X POST http://localhost:3001/chat \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Привет!"}]}'
```

---

## Остановка

Нажмите `Ctrl+C` в терминале, где запущена система.

---

## Проблемы?

### Ошибка "tsx не является командой"

Используйте `npm run launch` вместо `npx tsx scripts/launch.ts`.

### Порт 3001 уже занят

Измените порт в `.env`:
```
PORT=3002
```

### Нет keys.json

Скопируйте пример:
```bash
cp keys.json.example keys.json
```

И добавьте свои API-ключи.

---

## Структура команды

- `npm run launch` — запустить всё одним кликом
- `npm run sync` — только синхронизатор
- `npm start` — только runtime-сервер
- `npm run dev` — только дашборд
- `npm test` — запустить тесты
