# 🚀 Как запустить систему

## Быстрый старт (БЕЗ API-ключей!)

```bash
npm run launch
```

Эта команда автоматически:
1. ✅ Проверит конфигурацию
2. ✅ Запустит синхронизатор (добавит бесплатные провайдеры)
3. ✅ Поднимет сервер на порту 3001
4. ✅ Запустит дашборд на порту 3000
5. ✅ Откроет браузер

**Система работает СРАЗУ без API-ключей!** 🎉

### Бесплатные провайдеры (без ключей):

| Провайдер | Модель | Лимит |
|-----------|--------|-------|
| **OVHcloud** | Qwen3.5-397B-A17B | 2 RPM |
| **Kilo Code** | NVIDIA Nemotron 3 Ultra | 200 req/hr |
| **LLM7.io** | GPT-OSS-20B | 60 req/hr |

## Отправка запросов

### Способ 1: Через браузер (дашборд)

Откройте `http://localhost:3000` и перейдите на вкладку **«Демо failover»**.

### Способ 2: Через PowerShell

```powershell
$body = @{
    messages = @(
        @{ role = "user"; content = "Привет! Как дела?" }
    )
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Uri "http://localhost:3001/chat" -Method POST -ContentType "application/json" -Body $body
```

### Способ 3: Через curl (CMD)

```bash
curl -X POST http://localhost:3001/chat -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"Привет!\"}]}"
```

## Добавление своих API-ключей (опционально)

Если хотите больше провайдеров и выше лимиты:

1. Откройте `http://localhost:3000`
2. Перейдите на вкладку **«⚙️ Настройка»**
3. Добавьте ключи (Groq, Gemini, OpenRouter и др.)
4. Скачайте `keys.json`
5. Перезапустите систему

**Где получить бесплатные ключи:**
- Groq: https://console.groq.com/keys
- Google Gemini: https://aistudio.google.com/app/apikey
- OpenRouter: https://openrouter.ai/keys

## Проверка работы

```bash

```

```powershell
# Проверка работоспособности
Invoke-RestMethod -Uri "http://localhost:3001/health"

# Статус пула провайдеров
Invoke-RestMethod -Uri "http://localhost:3001/status"
```

## Остановка

Нажмите `Ctrl+C` в терминале, где запущена система.

---

## Проблемы?

### Порт 3001 уже занят
Измените порт в `.env`: `PORT=3002`

### Нет ответа от LLM
Проверьте `http://localhost:3001/status` — есть ли доступные провайдеры.

### Ошибки 429 (Rate Limit)
Система автоматически переключается на другой провайдер (failover). Если все провайдеры исчерпали лимит — подождите или добавьте свои ключи.
